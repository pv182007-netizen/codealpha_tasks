# CodeAlpha Task 4 – Sentiment Analysis

## Objective
Classify customer reviews into Positive, Negative, or Neutral sentiment.

## Tools
- Python
- Pandas
- Regular Expressions
- Matplotlib

## Method
A simple word-lexicon approach is used to demonstrate the NLP workflow.

## Run
`pip install pandas matplotlib`

Then:
`python sentiment_analysis.py`

For a stronger NLP project, this can later be upgraded using NLTK, VADER, or a machine-learning model.
